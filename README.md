# Eremita Jogos

Arquivos públicos dos jogos da Eremita (Super Senha, Perfil Secreto, Craquefoot…).

- `midia/<jogo>/` — imagens e vídeos dos posts do Instagram [@eremita.jogos](https://www.instagram.com/eremita.jogos/). A API do Instagram só publica a partir de um link público, servido pelo GitHub Pages: `https://talessouza.github.io/eremita/midia/<jogo>/<arquivo>`.
